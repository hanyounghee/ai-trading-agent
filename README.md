# AI 트레이딩 에이전트

AI 트레이딩 에이전트 모바일 프로토타입.

## 실행
- `index.html` — 에셋까지 포함된 단일 파일 빌드. 브라우저에서 바로 열면 됩니다. (GitHub Pages 배포용)
- `src/agent.dc.html` — 원본 소스. 같은 폴더의 `support.js`, `assets/`가 함께 있어야 동작합니다.

## 주요 기능

### 대화 흐름
- 인트로 → 채팅 전환, 종목 검색 / 차트 분석 / 주문 카드 응답
- 질문 전송 시 5~15초 랜덤 로딩 (AI 로고 + 스켈레톤 시머, 문구 3단계 전환)
- 응답 대기 중 전송 버튼이 중지 버튼으로 전환, 중지 시 `답변이 중지 되었습니다.` 안내
- 자연어 Q&A 12개 패턴 (매매 타이밍, 시장, 배당, 세금, 이용 가이드) 실제 답변 제공
- 매칭 실패 시 3종 안내 문구 중 랜덤 노출, 비속어는 무시하고 투자 관련 질문으로 유도

### 음성 입력
- Web Speech API(ko-KR) 인식
- 인식 종료 후 즉시 닫지 않고 분석 상태로 전환 — 4개 도트가 좌→우로 순차 펄스, `음성 분석중이예요` 캡션, 1.6초 후 전송
- 응답 대기 중에는 마이크 비활성 (탭 시 1.04x 스프링 바운스 + 햅틱 피드백만 발생, 레이아웃 이동 없음)

### 키보드 / 인터랙션
- 한글 조합 가상 키보드 (iOS 스타일: 44px 키, 6px 라운드·갭, 수정키, 홈 인디케이터 여백)
- 키보드 등장 시 입력 영역 패딩 36px → 20px 스무스 전환 (0.3s), 키보드는 전체 폭 유지
- 채팅 영역 터치 시 키보드 자동 닫힘
- 새 대화 아이콘 / 히스토리 시계 아이콘에 프레스 바운스 (스케일 + 스프링 이징)

```
src/assets/         이미지 에셋
```
